## 🎯 What is Zephyr AI?

Zephyr AI is a **full-stack fashion intelligence platform** that combines:

| Feature | Description |
|:---:|---|
| 💬 **AI Chat** | Talk to Zephyr like a personal stylist — get advice on outfits, colors, occasions, and trends |
| 📸 **Outfit Analyzer** | Upload a photo and get instant AI-powered outfit analysis with improvement suggestions |
| 🔥 **Trend Explorer** | Browse what's hot right now in fashion — street style, runway, seasonal picks |
| 🧬 **Style DNA** | Discover your unique style identity based on your preferences and history |
| 🎮 **Zen Games** | 11 interactive stress-relieving canvas games (Bubble Pop, Zen Piano, Smoke Art & more) |
| 📚 **Level Up** | Premium fashion guides — Color Psychology, Capsule Wardrobe, Streetwear Bible, etc. |
| 🎨 **Themes** | 6 stunning themes (Cosmic Purple, Ocean Blue, Rose Gold, Emerald, Sunset, Midnight) |
| 🔊 **Voice** | AI reads responses aloud in English or Hindi (Hinglish mode!) |

## 🚀 Quick Start

### 1. Clone & Open
```bash
git clone https://github.com/your-username/zephyr-ai.git
cd zephyr-ai
```

### 2. Add Your API Key
Open `ai-engine.js` and set your API key:
```javascript
config: {
    provider: 'gemini',
    apiKey: 'YOUR_GEMINI_API_KEY_HERE'
}
```

> 💡 **Supports:** Google Gemini (recommended) or OpenAI GPT

### 3. Launch
Simply open `index.html` in your browser. No build step needed!

```bash
# Or use a local server for best experience:
npx serve .
```

## 🔧 Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | Vanilla HTML5, CSS3, JavaScript (ES6+) |
| **AI** | Google Gemini API / OpenAI GPT API |
| **Vision** | Gemini Vision for outfit analysis |
| **Audio** | Web Audio API (games) + HTML5 Audio (ambient) |
| **Speech** | Web Speech API (voice readout) |
| **Storage** | localStorage (preferences, chat history, style memory) |
| **Design** | Custom CSS design system, CSS variables, `color-mix()` |

> **Zero dependencies.** No npm, no webpack, no frameworks. Pure vanilla web technologies.
